# Security policy

## Reporting a vulnerability

Report vulnerabilities privately through GitHub:
<https://github.com/structured-world/sflow-proto/security/advisories/new>.

Please do not open a public issue or pull request for a vulnerability. Include
the affected version or commit, how to reproduce the problem, and its impact as
you understand it. We acknowledge reports and keep you informed while a fix is
prepared and released.

## Supported versions

The API is pre-release: fixes land on `main` only.
